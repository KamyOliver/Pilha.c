Estrutura de Dados: Pilha em C

Projeto em linguagem C que implementa uma estrutura de dados do tipo pilha (stack) utilizando alocação dinâmica de memória.

Funcionalidades
Empilhar elementos
Desempilhar elementos
Verificar se a pilha está cheia
Verificar se a pilha está vazia
Exibir os elementos da pilha

Conceitos aplicados
Estrutura de dados LIFO (Last In, First Out)
Ponteiros
Alocação dinâmica (malloc)
Manipulação de memória
Recursão (Fatorial e Fibonacci)

pilha.c → Implementação da pilha
pilha.h → Definição da estrutura
teste_pilha.c → Testes da pilha
recursao.c → Funções recursivas
testePrint.c → Testes com printf

gcc pilha.c teste_pilha.c -o pilha ./pilha
